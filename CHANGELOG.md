# context-template ChangeLog

## 2.0.0 - TBD

### Changed

- **BREAKING**: Package is now ESM-only; the CommonJS build has been removed.
  Node.js >= 24 required.
- Convert source to TypeScript (`src/`); type declarations are now published.
  The exported API is unchanged.
- Replace the webpack + rollup build with a single `tsc` build; the
  `contexts/*.jsonld` artifacts are still generated by `bin/serialize.js` as
  part of `build`.
- Switch to pnpm, eslint 10 (flat config), prettier, vitest (node tests), and
  playwright (browser smoke test).
